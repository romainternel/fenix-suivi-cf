# Régression — v261 (STORY-36 : refonte lisibilité du mode Articulation)

**Agent :** Regression Guardian
**Date :** 2026-09-06
**Changement :** `js/page-analyse.js` (repositionnement des postes via une nouvelle formule géométrique, retrait du texte d'efficacité des ronds, fusion de la référence globale dans le panneau de blocs, nouveau bandeau de contrôles), `css/style.css` (nouvelles classes `.artic-control-bar`/`.artic-manual-indicator`/liseré `.artic-poste.{fort,moyen,faible,noref}`, `.artic-poste.selected` passé en `outline`)

## Analyse de risque

Zone modifiée = le mode Articulation dans son ensemble (I22 de la checklist), déjà en production depuis v258 et retouché à 3 reprises (v259, v260, v261). Risque principal identifié par le Risk Analyst (`docs/risks/articulation-lisibilite.md`) : collision visuelle entre le nouveau liseré d'efficacité (`box-shadow`) et le halo de sélection existant, jusqu'ici implémenté lui aussi en `box-shadow`.

## Vérification

- **R1 (collision outline/box-shadow)** : vérifié explicitement par `getComputedStyle` sur un poste sélectionné et coloré (`moyen`) — `outline` et `box-shadow` sont bien tous deux appliqués simultanément, confirmé une seconde fois par un clic réel (E2E-20, parcours #3). RAS.
- **R2 (proximité postes/but sur iPad)** : testé à 768px de large — aucun chevauchement entre les postes P1/P6 du dispositif 0-6 et le rectangle du but. RAS.
- **Non-régression Vue générale / Matrice 2×2** : re-testées après les changements (clic réel sur les deux boutons), comportement identique à avant STORY-36.
- **Non-régression bascule Attaque/Défense** : le bouton Articulation se désactive/réactive correctement, reset automatique vers "Vue générale" confirmé par clic réel sur "⚡ Attaque".
- **Non-régression vue match / vue saison** : le mode Articulation testé dans les deux contextes (`renderEncFamillesSection()` reste la fonction partagée, aucune duplication introduite).
- **Aucun changement de donnée** : `computeArticulationStats`, `_articBlockEff`, `ARTIC_BLOCKS` non modifiés — les chiffres affichés (efficacités, nombres de séquences) sont strictement identiques à v260, seule leur présentation a changé.
- **Navigation générale** : 0 erreur console sur l'ensemble des parcours testés (Developer, QA, E2E).

## Verdict

**RAS** — aucune régression détectée. Checklist mise à jour (I22, historique consolidé pour éviter que la cellule ne devienne intenable — le détail des bugs v258/v259 reste accessible dans leurs rapports QA/E2E dédiés plutôt que dupliqué ici).
