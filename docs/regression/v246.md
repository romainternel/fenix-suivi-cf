## Contexte

Correctif appliqué le jour même de l'audit complet (`docs/regression/audit-complet-2026-09-01.md`), qui avait détecté que 3 features (I1 onglet Gardien, I2 table GB, I3 graphique gardien) échouaient silencieusement à cause d'une comparaison stricte entre la colonne `Gardien` de la feuille Excel (prénom seul, ex. "Gabin") et le format court "Prénom.Initiale" utilisé partout ailleurs dans l'app (ex. "Gabin.S").

## Correctifs appliqués

1. **`computeGbEncStats()`** (`js/page-analyse.js:2424`) : `GARDIENS_FENIX.includes(gardien)` → `GARDIENS_FENIX.some(g => matchPlayerName(gardien, g))`.
2. **`calculateGardienNotes()`** (`js/page-notes-graph.js`) : correction plus profonde que prévue initialement — la fonction agrège en 2 passes (tirs adverses, puis bonus d'actions offensives), chacune utilisant un format de nom différent comme clé du dictionnaire de résultat (prénom seul en passe 1, format court en passe 2), créant deux entrées distinctes pour le même gardien au lieu d'une seule fusionnée. Corrigé en résolvant systématiquement vers la forme canonique de `GARDIENS_FENIX` dès la passe 1.
3. **`updateGbGraph()`** (`js/page-notes-graph.js:611`) : `row[COLS.gardien] !== gardien` → `matchPlayerName((row[COLS.gardien]||'').toString().trim(), gardien)`.

## Vérification

Testé en conditions réelles (serveur local, données réelles importées) pour les 3 gardiens réels (Gabin.S, Noah.O, Enzo.D) :

- **I1** : onglet Gardien de la page Analyse affiche désormais "42% d'arrêts", tableau par système adverse correct (Isoler 4 tirs/1 arrêt/25%, etc.), cohérent avec le "Bon gardien : 42% d'arrêts" déjà affiché dans le résumé de match.
- **I2** : table GB de la page Notes affiche les 3 gardiens en une seule ligne chacun (vérifié explicitement qu'il n'y a plus de doublon "Gabin"/"Gabin.S" — `calculateGardienNotes()` retourne exactement 3 clés), stats arrêts/buts/score/bonus/temps de jeu cohérentes.
- **I3** : graphique de progression pour un gardien (`goToGbGraph('Gabin.S')`) rend un canvas correctement dimensionné (1094×607, contre 300×150 par défaut avant fix) avec courbe et barres visibles.
